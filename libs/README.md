# Local compile-only dependencies

`emi-1.1.24+1.21.1+neoforge.jar` is the official NeoForge asset from EMI's
GitHub release `1.1.24+1.21.1`. It is used only at compile time to avoid the
unreliable SleepingTown Maven endpoint; it is not bundled into Animania.

Source: https://github.com/emilyploszaj/emi/releases/tag/1.1.24%2B1.21.1
