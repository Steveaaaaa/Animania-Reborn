# EMI compile dependency

The local Maven directory contains EMI 1.1.22 for Forge 1.20.1, downloaded from
its official Modrinth distribution. ForgeGradle remaps it for compilation; it is
not bundled into the Animania jar.

Source: https://github.com/emilyploszaj/emi
Distribution: https://modrinth.com/mod/emi/version/1.1.22+1.20.1+forge
